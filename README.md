# Phoenix DRX

**SPT 存档编辑器** —— 一个 Windows 桌面程序，用来给《单机塔科夫（SPT）》的存档改数据：等级、钱、技能、商人好感、任务、藏身处、仓库物品。

界面是暗色沉浸风，纯本机离线运行，不联网、不注入、不挂钩子。

---

## 它能做什么

| 页面 | 能改什么 |
|---|---|
| 角色 | 昵称、阵营、等级与经验（双向联动，上限按服务器经验表）、语音、头型、口袋格数 |
| 健康 | 九个部位的血量、水分、能量（当前值与上限） |
| 技能 | 45 项通用技能等级、22 项武器熟练度，上限按服务器熟练表算 |
| 商人 | 12 个商人的好感度、等级、销售额 |
| 任务 | 567 条任务的状态（未接/进行中/已完成）、完成条件、计时 |
| 藏身处 | 28 个区域的等级、生产配方（只改你点的那一项，其余原样保留） |
| 仓库 | 网格视图、添加物品、按名称/短名/编号搜索、三种货币加减、装备加成（仓库行数） |
| 检视 | 物品详情、改装指标（人机工效、后坐力）、配装预览 |
| 预设 | 自己的武器/装备预设入库、12 套精选配装一键成套入库 |
| 备份 | 每次写入前自动备份，可一键回滚 |
| 账号 / 设置 / 关于 | 服务器路径、语言、更新检查、公告 |

## 数据安全

- **任何一次写入存档之前，都会先落一份备份**，保存在 `%APPDATA%\com.phoenix.drx\backups\<存档ID>_<服务器ID>\` 下，自动保留最近 10 份。
- 改藏身处这类嵌套结构时采用「按 key 合并」而不是整块重建，只动你改的那一项，其余字段逐字保留。
- 备份页可以随时回滚到任意一份历史备份。

## 要求

- Windows 10 / 11 x64
- SPT 4.1.x（含 `SPT_Runtime` 目录结构；老版 `SPT` 目录同样支持）
- 程序会自动在服务器根目录下寻找 `SPT_Runtime` 或 `SPT`

## 自己构建

需要 Node 20+、Rust stable、WebView2。

```bash
npm install
npm run gate        # 类型检查 + lint + 单元测试
npm run tauri build # 产出安装包
```

开发者须知见 [AGENTS.md](AGENTS.md)，交接入口见 [docs/guides/交接-新对话必读.md](docs/guides/交接-新对话必读.md)。
