# 视觉基线清单（Phoenix-DRX）

> 2026-10-16 定稿，与稿图同等效力；**2026-10-17 token 换版**（16 屏稿图收官后按稿图 `:root` 整体换版第三节，记录见 §六）。
> 来源：旧 Phoenix（Phoenix-master）实码提炼 + 本项目裁决 + 16 屏稿图（`docs/prototypes/`）定稿值。
> Token 前缀统一 `--phx-*`，单一来源文件 `src/renderer/src/design/tokens.css`，由 vitest 完备性测试卡死。
> 原则：**用户看到的每一个像素都必须是设计出来的**——任何暴露浏览器/操作系统默认视觉的东西都算违规，除非列入「系统级例外」。

## 四、组件携带行为基线

自建组件不是「能看就行」，每个组件交付时必须自带：

- **三态**：hover / active / disabled（悬停反馈按稿图面/填充体系：`--phx-fill-quaternary` 或 `--phx-surface-2`；disabled 置灰且禁点击）；
- **键盘可达**：Tab 焦点环（自定义样式：强调色 2px 描边，不许系统默认蓝框也不许无焦点环）、Enter/Space 激活、Esc 关闭弹层；
- **动效尊重偏好**：跟随系统 `prefers-reduced-motion` 与项目内「减少动态效果」设置（见感官层基线）；
- **文字层级**：字号跟随稿图定稿值（§三 字体段），不临时拍新字号；
- **z-index 层级带**：基础 0 / 顶栏 10 / 下拉浮层 100 / 弹窗 200 / toast 300——token 化（`--phx-z-*`），禁止随手写 9999。

### 分段切换交互规格（2026-10-19 随 PhxSegmented 全仓收编入册）

全仓 10 处分段切换统一收敛到 `PhxSegmented` 组件（参考 tengriqaghan Segmented 视觉语言）：

- **液体滑块**：选中项背后一块滑块（`--phx-surface-2` 底 + `--phx-r-btn` 圆角）随选中项滑动，绝不用瞬移硬切；滑动 `--phx-dur-norm` + `--phx-ease-emphasized`，只动 `transform`（合成器路径）。
- **悬停光源**：鼠标移入非选中项亮起跟随光斑（opacity 过渡，`--phx-dur-fast`），光源不干扰选中态滑块；`prefers-reduced-motion` 双通道下全部退化为瞬时切换。
- **尺寸两档**：`sm` = 12px 字号紧凑档（各页筛选统一档）/ `md` = 28px 高大档（character 主档，稿图原值；BEAR/USEC 水平内边距稿图原值 22px 经 `--seg-pad-x` 变量出口覆盖，默认 18px）。
- **语义**：容器 `role` 由调用方声明（页签组 `tablist`、模式/阵营 `radiogroup`）+ `aria-label`；音效沿用 §二「普通点击 → `ui`」档，组件内单点播放，页面不再各自触发。
- **调整**：页面如需覆盖布局（如靠右），包一层页面内 wrapper div，把 CSS 变量覆盖放 wrapper 上（自定义属性继承穿透组件），组件不设 class/style 透传。
