# 视觉基线清单（Phoenix-DRX）

> 2026-10-16 定稿，与稿图同等效力；**2026-10-17 token 换版**（16 屏稿图收官后按稿图 `:root` 整体换版第三节，记录见 §六）。
> 来源：旧 Phoenix（Phoenix-master）实码提炼 + 本项目裁决 + 16 屏稿图（`docs/prototypes/`）定稿值。
> Token 前缀统一 `--phx-*`，单一来源文件 `src/renderer/src/design/tokens.css`，由 vitest 完备性测试卡死。
> 原则：**用户看到的每一个像素都必须是设计出来的**——任何暴露浏览器/操作系统默认视觉的东西都算违规，除非列入「系统级例外」。

## 一、原生件替换表（禁用 → 项目替代）

| 类别 | 禁用（原生默认视觉/行为） | 项目替代 | 机器卡死 |
| --- | --- | --- | --- |
| 对话框 | `window.confirm` / `alert` / `prompt` | 自建确认/警示弹层（PhxDialog，暗色卡片风格） | eslint `no-restricted-syntax`（✅ 已生效，`eslint.config.mjs`） |
| 轻提示 | 浏览器默认 toast | 自建 toast 服务（右上角、可堆叠、success/warning/error 变体） | review 清单 |
| 悬停提示 | 原生 `title` 属性 | 自绘 Tooltip（延迟 300ms、暗底、渐变描边） | eslint（✅ 已生效，含 `bind:title`） |
| 表单控件 | 原生 `select` / `checkbox` / `radio` / `switch` | 项目自绘：开关 sw、下拉 dd、复选框 ck（见 §七；2026-10-17 随 15 屏拍板，naive-ui 方案作废） | review 清单 |
| 文本输入 | 原生默认输入框 | 统一输入样式（focus ring 用强调色 `--phx-accent`，三态齐全） | tokens 强制 |
| 滚动条 | 原生滚动条 | 沿旧 Phoenix：卡片列表区**隐藏滚动条**保留滚动；表格/仓库网格区用 4px 细滚动条（`--phx-scrollbar-w: 4px`；2026-10-17 拍板保留，稿图隐藏仅为截图美化） | 全局 CSS 一次性覆盖 |
| 文本选区 | 默认蓝底白字 | `::selection` 强调色半透明 | 全局 CSS |
| 右键菜单 | 原生 contextmenu | 自绘上下文菜单（仓库物品操作用；未做前不拦截默认） | review 清单 |
| 托盘菜单 | 原生托盘右键菜单（Win32 只跟随系统主题渲染，无法按应用着色；2026-10-18 裁决废弃） | 自绘托盘面板：无边框 WebviewWindow（`/tray` 路由），实心 `--phx-surface-2` 底（透明窗内 backdrop-filter 够不到窗外桌面，玻璃拟态不可用），全 `--phx-*` token 渲染，贴托盘图标弹出、失焦/Esc 收起 | review 清单 |
| 日期/颜色选择 | 原生 picker | 一期无此需求；出现时先自绘再上代码 | review 清单 |

## 二、系统级例外（允许原生，禁止自绘）

- 文件/目录选择对话框（选 SPT 服务器目录、导入导出预设）——`dialog.showOpenDialog`
- 系统托盘图标——`TrayIcon`（图标位 OS 无自绘口；右键面板为自绘件，见 §一「托盘菜单」行）
- 操作系统输入法候选框
- 屏幕阅读器等无障碍基础设施的原生行为
- 自动更新器的系统级弹窗（electron-updater，若启用）

## 四、组件携带行为基线

自建组件不是「能看就行」，每个组件交付时必须自带：

- **三态**：hover / active / disabled（悬停反馈按稿图面/填充体系：`--phx-fill-quaternary` 或 `--phx-surface-2`；disabled 置灰且禁点击）；
- **键盘可达**：Tab 焦点环（自定义样式：强调色 2px 描边，不许系统默认蓝框也不许无焦点环）、Enter/Space 激活、Esc 关闭弹层；
- **动效尊重偏好**：跟随系统 `prefers-reduced-motion` 与项目内「减少动态效果」设置（见感官层基线）；
- **文字层级**：字号跟随稿图定稿值（§三 字体段），不临时拍新字号；
- **z-index 层级带**：基础 0 / 顶栏 10 / 下拉浮层 100 / 弹窗 200 / toast 300——token 化（`--phx-z-*`），禁止随手写 9999。
