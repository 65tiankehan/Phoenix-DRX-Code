# 感官层基线（Phoenix-DRX）

> 2026-10-16 与视觉基线同批定稿（写第一个 UI 组件前）。
> 范围：**音效 / 动效 / 动态图标**。核心原则：**感官反馈必须挂在真实状态变化上**（不放假音效、不放假动效），且**任何一层都可全局关闭**。

## 一、音效层

### 裁决变更：2026-10-18 启用音效（参考 tengri-novel 方案）

原裁决「一期不启用音效」（2026-10-16）由用户主动变更开启。**基线顺序不变，已按顺序执行**：先补映射表（本条）→ 建 `playSound(kind)` 统一服务（`src/lib/sound.ts` 单一来源）→ 资产层（本方案为零音频文件，资产步骤消解为代码）→ 设置层总开关 → 再写接入代码。

**技术方案：WebAudio 程序化合成，零音频文件**（参考 `D:\TengriQaghan\tengri-novel` 的 sounds.ts，只读参考）：

- `AudioContext` 惰性单例；首次调用或 suspended 时 resume；
- 音色 = 振荡器 + lowpass(3000Hz) + 指数包络（攻击 0.015s、衰减到 0.0001）；主音量 gain 0.6 克制；
- 持久化 localStorage `phx.sound`，默认开；
- **组件/页面禁止直接摸 AudioContext**（`new Audio` 已有 eslint 卡点；直连 `new AudioContext` 同属越层，一律走 `playSound(kind)`）；
- 全站总开关在设置页（真实消费链路，读写 `phx.sound`）。

**交互→音效映射表**（新增交互必须先入表再实现，禁止放假音效）：

| kind | 语义 | 触发点 |
| --- | --- | --- |
| `nav` | 切页 | dock / 侧栏链接，且**仅路由真正变化时** |
| `ui` | 普通点击 | 分段筛选、折叠头、普通按钮 |
| `toggle` | 开关切换 | PhxSwitch（组件级单点实现） |
| `pop` | 弹出 | 菜单弹出、PhxDialog 打开（组件级单点实现） |
| `gain` | 数值增益 | 补齐缺失值、数值步进 |
| `success` | 保存/批量成功 | 保存成功、批量操作完成 |
| `alert` | 危险/失败 | 危险确认按钮、操作失败 |

- 同一语义全站同一 kind；映射表没有的交互先补表。
- 音效层独立关闭：只受设置页总开关控制；reduced-motion（动效偏好）不关音效。

## 二、动效层

### Motion Tokens（进 `tokens.css`，vitest 完备性测试核对）

| Token | 值 | 语义 |
| --- | --- | --- |
| `--phx-dur-fast` | `150ms` | 微交互（开关、按下） |
| `--phx-dur-norm` | `300ms` | 常规（卡片 hover、页面切换）——旧 Phoenix `transition: transform .3s, box-shadow .3s` 的档位 |
| `--phx-dur-slow` | `500ms` | 转场 |
| `--phx-ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | 出场/入场 |
| `--phx-ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 退场 |
| `--phx-ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | 强调（弹层缩放） |

组件禁止自造曲线与时长。

### 语义化动效约定

- **页面入场**：旧 Phoenix 用 animate.css `backInLeft`。本项目沿用 animate.css 4.x（依赖已引入）作为入场库**单一来源**；自定义 keyframes（`phx-*` 前缀）只用于 animate.css 覆盖不了的场景，定义集中在一处。
- **同一语义全站同一实现**：区块级联入场、卡片悬停、弹层缩放各自只有一个实现。
- 动效实现契约：
  - 入场动画终态必须 `transform: none`（`fill both` 留存末帧 transform 会让内部定位元素退化）；
  - 动画只动 `transform` / `opacity`（合成器路径），不动布局属性；
  - 悬停光晕（box-shadow）与位移（transform）的 transition 分离到正确载体。
- **强制关停双通道**：系统 `prefers-reduced-motion` 媒体查询 + 项目设置页「减少动态效果」开关（html 根类 `phx-reduced-motion`），**任一命中即全局禁用过渡/动画**。tokens.css 已含媒体查询侧；设置侧随设置页实现接入。
- 动效是反馈不是装饰：每个动效必须对应一个状态变化（进入/切换/确认/失败），说不清对应什么状态就不要做。

### 通用交互动效（2026-10-18 随音效启用追加，参考 tengri-novel motion.css）

| 动效 | 语义（对应状态变化） | 实现 | Token |
| --- | --- | --- | --- |
| 按钮按压 | 按下→可点击反馈 | 全站 `button:active` brightness(0.92) 一条规则（app.css）；dock 链接同值。**禁用 transform 缩放**（2026-10-19 事故：缩放收缩命中区，mouseup 滑出按钮致事件委托 click 失效，详见门禁清单事故登记） | `--phx-dur-fast` + `--phx-ease-out` |
| 页面入场 | 路由变更 | layout 层 `{#key pathname}` 包裹，8px 上移淡入，**终态 `transform: none`** | `--phx-dur-norm` + `--phx-ease-out` |
| 骨架屏呼吸与交接 | 数据加载中（缓冲占位）→ 数据到达 | 每页自绘**镜像骨架**（`.phx-sk` 色条族按真实页面布局拼装，禁用通用变体），数据到达时内容 `.phx-fade-in` 上移淡入、骨架层 `.phx-boot.gone` 同步淡出，两者并行交叉淡化；reduced-motion 双通道自动降级 | 呼吸周期约 1.2s（循环动画非过渡，token 档位不适用）；交接用 `--phx-dur-norm` + `--phx-ease-out` |
| 分段液体切换 | 分段选中值变化 | PhxSegmented 滑块（绝对定位量宽）随选中项滑动（2026-10-19 兑现，参考 tengriqaghan Segmented） | `--phx-dur-norm` + `--phx-ease-emphasized` |
| 分段悬停光源 | 悬停→可点击反馈 | PhxSegmented 鼠标移入项亮起跟随光斑（opacity 过渡），悬停光源不干扰选中态 | `--phx-dur-fast` + `--phx-ease-out` |
| dock 滑动指示器 | 路由变更→选中项迁移 | PhxDock 指示条随当前路由项滑动（ResizeObserver 重测量，2026-10-19 兑现 §二 dock 注记的承诺） | `--phx-dur-norm` + `--phx-ease-emphasized` |
| 折叠组展开收起 | 折叠头点击→组体显隐 | 单行 grid `1fr↔0fr` 高度过渡（quests/health/skills 折叠组），visibility 延迟切换保证收起后内容不可聚焦；reduced-motion 双通道一并关停 | `--phx-dur-norm` + `--phx-ease-emphasized` |

- 骨架屏是**加载缓冲语义**：数据到达前的占位；禁止拿骨架屏掩盖失败态（失败必须显示真错误）。
- 骨架屏**必须镜像真实页面布局**（2026-10-20 用户裁决）：每页用自身布局 class 拼装骨架 DOM（复用 .toolbar/.scroll/.qcard 等获得相同几何与底色），禁止通用变体（一行 N 张通用卡等敷衍形态）；`.phx-sk` 原语族与 `.phx-boot` 常驻层定义于 app.css，交接动画为内容淡入 + 骨架淡出并行。原 PhxSkeleton 组件已删除（2026-10-20）。
- 页面入场实现于 layout 单点（一处编辑全站生效），遵守上文终态与合成器契约。

### 窗口 chrome 感官映射（Win11 标题栏 + dock，2026-10-17 随稿图入册）

视觉基线 §六的 Win11 窗口 chrome（自绘标题栏三键 + 底部胶囊 dock）的交互反馈全部挂在既有 Motion Tokens 上，不新造曲线/时长：

- **标题栏三键**：悬停背景淡入用 `--phx-dur-fast`（150ms）+ `--phx-ease-out`，只动 background/opacity；关闭键悬停红底为 Win11 官方色 `#c42b1c`（系统级白名单，见视觉基线 §六）；reduced-motion 下退化为瞬时变色。
- **底部胶囊 dock**：玻璃拟态底（backdrop-filter blur）+ 选中项指示；项悬停/切换的位移与透明度过渡用 `--phx-dur-fast`，页面切换联动指示器移动用 `--phx-dur-norm` + `--phx-ease-emphasized`。**2026-10-19 兑现**：选中项指示落地为滑动指示条（PhxDock，随路由项移动）；悬停跟随光源与 PhxSegmented 同款规格（nav 层事件委托写 `--mx/--my`）。
- chrome 所有过渡只动 `transform` / `opacity`（合成器路径），符合上文动效实现契约；`prefers-reduced-motion` 与项目设置双通道任一命中即全部退化为瞬时切换。
- chrome 属全局壳层，不受「区块级联入场」等页面级约定约束，但同样必须能说清对应的状态变化（悬停→可点击、切换→页面变更）。

## 三、动态图标层

- 图标体系：`@vicons/ionicons5` 描边风格，尺寸档位 **16 / 24**（菜单箭头 24、行内 16），来源单一。
- 动态图标：一期无需求（不装饰性旋转）。出现真实场景（加载/成功失败形变、播放态切换）时先补本节再实现。
- 每个动态图标必须有一个静态终态（reduced-motion 下退化为静态图标）。
