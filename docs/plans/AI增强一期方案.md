# AI 增强一期方案（AI 助手 + 服装编辑）

> 状态：**调研完成，待用户批准**（2026-10-24）。用户原话锚点：「我想要整一套满配，有什么推荐，推荐完后应该自动把安装一整套，还可以改仓库的钱，还可以换衣服——AI 助手给我灵活配置的感觉，这是最基础的」。

## 一、定位与体验主张

**AI 是「跨域指挥台」，不是第 12 个孤岛页**：一句话 → AI 出跨域方案（装备/钱/服装/技能/任务…）→ **预览卡片逐项确认 → 走备份链执行** → 随手微调。差异化在于：别的编辑器是「一堆滑块让你自己懂」，我们是「你说人话，它办妥当」。

**融合方式（回答「怎么融进现有界面」）**：
- **入口**：命令面板（Ctrl+K）加「问 AI」+ 各域页面顶部「AI 推荐」按钮（带当前页上下文跳转，如 `/assistant?from=skills`）+ 首页动态栏引导条（可关）；**dock 不加新项**（11 项布局已定稿，AI 以独立路由 `/assistant` 承载）。
- **执行确认**：新共享组件「操作预览卡」（模式对齐 PhxIssueSheet：列出每条操作、改什么从→到、逐项勾选、整体确认）。
- **安全铁律延伸**：AI 只允许调用**白名单操作集**（现有 Rust IPC 命令的子集），绝不直接写 JSON；每次执行前自动走存档备份链（「写入前必须备份」铁律的 AI 版）。

## 二、一期范围

### 2.1 AI 配置底座（设置页新增「AI 助手」组，稿图 30）

- **统一客户端**：Rust 侧 OpenAI 兼容协议（`reqwest`，已是依赖），base URL + API key + 模型名三件套可配 → 同时兼容 **DeepSeek / GLM / SiliconFlow / Ollama / LM Studio**；
- **key 存系统钥匙串**（GitHub 同步已有 keyring 通路，token 不出 Rust 的既有模式复用）；
- **Ollama 探测**：探测 `localhost:11434` 是否在跑 + 列模型，在则可选（离线零成本路径）；没装就置灰（诚实原则，无假开关）；
- **隐私边界（硬规则）**：默认关闭；开启后每次请求只携带**执行该操作所需的最小上下文**（如改技能只发技能段），发送内容在请求前展示；绝不上传完整存档。

### 2.2 AI 助手面板（`/assistant`，稿图 29）

- 对话流：用户一句话 → 模型以**工具调用**产出操作计划 → 前端渲染**操作预览卡** → 逐项勾选 → 确认执行（走备份链）→ 结果回执入对话流；
- **白名单操作集 v1**（每条 = 结构化 schema，Rust 侧逐条校验执行）：

| 操作 | 映射到既有命令 | 备注 |
| --- | --- | --- |
| 设置技能等级 | skills_save | 含拉满/指定值 |
| 调整商人好感/等级 | traders_save | 含全满 |
| 推进/完成任务 | quests_save | 按任务 id/名称匹配 |
| 调整货币 | stash 货币堆编辑 | 需补一个 money_set 命令（小） |
| 解锁服装/换头型语音 | clothing_unlock + customization_set | 新命令（见 2.3） |
| 应用装备方案 | preset_add / build_to_stash / scav | 已有 |

- 上下文注入：仅当前域的摘要（JSON 压缩形态），控制在 1–2k token。

### 2.3 服装编辑本体（独立屏，稿图 31——非 AI 用户也直接可用）

**调研结论（4.1.1 参考仓，只读核实）**：
- `profile.customisationUnlocks[]`：`{ id, source: "unlockedInGame", type: "suite" }`——服装解锁列表，增删即解锁/上锁；
- `character.customization`：`{ head, voice }`——头型与语音；
- **服装目录**：服务器 database 的套装类目（参考仓 `ServerClasses/TraderSuit.cs`，Ragman 套装清单 + `IsSuitUnlock` 判定），UI 列表与预览数据来源于此。

**屏内容**：服装网格（已解锁/可解锁两态，预览图沿用 server database 资源路径）+ 头型/语音两个下拉 + 一键全解锁开关。工作量与角色页其他域同级。

## 三、模型推荐（用户自选自担费用，我们不内置、不收费）

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 本地（Ollama） | **Qwen3 4B / 8B** | 中文最强、支持工具调用；8GB 显存体验佳 |
| 云端 BYOK | **DeepSeek-V3**（deepseek-chat）、**GLM-4.5-Flash**（免费档） | 便宜/免费、中文好、OpenAI 兼容 |
| 语义搜索（三期） | bge-small-zh-v1.5（ONNX 内嵌，~100MB） | 纯本地，CPU 可跑 |

**明确不做**：进程内跑大模型（内存/体积不可行）；自建后端（违背零服务器+永久免费铁律）。

## 五、风险与边界

1. **模型输出不可靠**：白名单 schema 硬校验 + 预览确认双保险，AI 说不算、确认了才算；
2. **隐私**：默认关、最小上下文、发送前展示；文档与公告如实声明「使用云端 AI 时相关数据会发送到你配置的服务商」；
3. **成本**：零——BYOK/Ollama 均为用户自担；
4. **服装目录依赖 SPT 版本**：目录从服务器 database 现读（与数据层 4.1.1 校准同源），版本升级自动跟随；
5. **免费口径**：AI 功能随应用免费，服务费用户自付，公告口径如实。
