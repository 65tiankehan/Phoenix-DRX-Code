# Phoenix DRX 营销计划书

> 建立于 2026-11-25（v0.2.9 发布当日）。本文件只记「怎么让人知道、怎么判断有效」，不涉及功能规划。
> 数据口径：GitHub API 实时值，不是估算；每次复盘把新数字补到 §二 的表格末行。

## 一、目标

**六个月内的唯一目标：把「每版几百下载」变成「有稳定自然流量 + 有社会证明」。**

不做的事：不投广告、不买量、不做付费推广、不刷 star。项目免费且没有收入，营销成本必须压在「写内容的工时」里。

判据（三条，按顺序成立才算成功）：

1. **社会证明**：GitHub star ≥ 100，Forge 评价/订阅有可见数量。
2. **自然流量**：任意新版本发布后 72 小时内**真实下载**（扣掉 `latest.json` 自动更新请求）≥ 80（不靠发帖也能达到，即 Forge 站内搜索与推荐已经生效）。
3. **渠道资产**：至少两个渠道（俄语论坛 + 中文社区）能带来可测量的增量（单次发帖 72 小时真实下载增量 ≥ 50）。

## 三、定位与卖点排序

一句话定位：**免费、离线、带自动备份的 SPT 存档编辑器，界面九种语言。**

卖点按对玩家的说服力排序（发帖时严格按这个顺序，不要从功能表开始）：

1. **不会弄坏档** —— 每次写入前自动备份，保留 10 份，备份页一键回滚。这是塔科夫玩家最怕的事。
2. **九种语言，词条按游戏内官方译法** —— Схрон / Lager / Réserve / Almacén / Schowek / Esconderijo / Depo，不是机翻；商人名保留原文。俄语玩家从 0.2.4 起就在要这个。
3. **改得动真东西** —— 等级、钱、技能、商人、任务、藏身处、仓库物品、预设成套入库。
4. **免费且没有暗门** —— 无激活码、无会员、无功能锁、仓库里没有授权校验代码；连开发成本都公开了（1,912.21 元 / 9 个月）。
5. 视觉：暗色沉浸风，不像常见的小工具界面。（这是加分项，不作主打。）

| 渠道 | 优先级 | 现状 | 下一步动作 |

**顺序原则**：先修 GitHub 的「门面」，再发帖。否则来人点进仓库看到 0 star、空 topics、无截图，转化直接归零。

## 八、度量与复盘

- 每次发帖记录：渠道 / 时间 / 帖子链接 / 发帖前 24h 的累计下载 / 72h 后的累计下载 / 差值。
- 每版发布后记录：GitHub stars、Forge 订阅或评价数、各语言下载占比（能拿到的话）。
- 复盘结论只写两条：**哪个渠道有效**、**哪个卖点被回应最多**。其余信息不记录，避免文件变成流水账。

---

## 九、风险与禁忌

- **不要承诺做不到的事**：界面里出现「即将开放」的元素（如口袋管理）在宣传中一律不提。
- **不要用「最强/唯一/第一」**：SPT 编辑器不止一个，比较式措辞会被社区反感。
- **不要在 Reddit 用营销腔**：先写「我用它做了什么」，再给链接；不要放二维码、不要放短链。
- **不要跨语言刷同一张图**：俄语帖配俄语界面截图，中文帖配中文，英文帖配英文；语言不匹配会立刻被识破。
- **数据说话**：成本、下载数、star 都是公开可查的，说错一次会毁掉「免费诚实」这条唯一的护城河。

## 附录：社区搭建的「一句话交接模板」

> 同一个动作（建社区 → 锁权限 → 置顶三语帖 → 铺邀请链接）在别的项目上复用，只需换掉「装什么、出问题看哪里」两处的项目口径。下面两版都是实测走通过程后写的。

**存档编辑器 / 工具类**（本项目用的版本）：

```text
给我这个项目建一个 KOOK 社区并把它变成能用的支持入口：服务器名用项目名、图标用现有 128px 图标；频道只要 5 个（分类「开始这里」下 #公告 #下载与安装 #问题反馈，分类「交流」下 #闲聊 和一个语音），#公告 与 #下载与安装 把 @全体成员 的「发送消息」设为拒绝（KOOK 权限是三态 ✕拒绝/╱继承/✓允许，频道与分类权限同步时改完要选「不同步」），两个频道各填一句频道主题；然后发两条置顶帖（#下载与安装＝几种安装包的区别＋SmartScreen/WebView2/程序目录/备份路径，#公告＝最新版发布说明），中英俄三语混排一条消息；最后把「永不过期、不限次数」的邀请链接铺到四处——发版页 Release 说明、README 首屏、官网下载卡、Forge 模组页描述末尾，铺完逐一回读线上页面确认真的生效。
```

**塔科夫客户端模组**（不同性质，别混用上面那版）：

```text
给我这个塔科夫客户端模组建一个 KOOK 社区并把它变成能用的支持入口：服务器名用模组名、图标用模组图标；频道只要 5 个（分类「开始这里」下 #公告 #安装与兼容 #问题反馈，分类「交流」下 #闲聊 和一个语音），#公告 与 #安装与兼容 把 @全体成员 的「发送消息」设为拒绝（KOOK 是三态权限 ✕拒绝/╱继承/✓允许，频道与分类权限同步时改完要选「不同步」），两频道各填一句频道主题；然后发两条置顶帖——#安装与兼容 写清依赖（BepInEx/SPT 版本要求）、两种装法、以及最常见的三类报错和日志文件位置；#公告 写这一版的「支持的 游戏版本 × SPT 版本」兼容表与改动要点，中英俄三语混排一条消息；最后把「永不过期、不限次数」的邀请链接铺到模组发布页（Forge / sp-mod）、README 首屏、官网或模组帖，铺完逐一回读线上页面确认真的生效。
```
