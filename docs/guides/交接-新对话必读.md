## 续卷约定

1. 每卷限定一个阶段的大小：**目标单卷 ≤ ~100KB**。
2. 写满开新卷：新卷从上一卷封存点接着记（用白板 `docs/guides/卷模板.md`）；旧卷头部加封存指引，正文不再续写。
3. 每卷头部必须有卷链（主入口 / 上一卷 / 下一卷）；本文件保持「最新卷」指针，开新卷时更新索引表。
4. 本主入口永远叫 `交接-新对话必读.md`（AGENTS.md 引用此名），保持小。
5. 何时开卷二：卷一满 ~100KB，或阶段切换（如「稿图阶段」单独成卷）。
