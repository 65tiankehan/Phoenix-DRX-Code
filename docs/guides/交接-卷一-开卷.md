### §二.1 项目定义与四项裁决（用户已批）

- **起因**：新编辑器 Phoenix-DRX 立项。四个仓角色：Phoenix-master=UI 供体；SPT-AKI-Profile-Editor-4.0.1=功能基准（适配 SPT 4.0.1–4.0.7）；Standard Project Goal=流程标准；Phoenix-DRX=落地仓。
- **用户拍板（2026-10-16）**：
  1. 窗口形态：**放大窗口、保留视觉风格**（约 1100×720 桌面尺寸，暗黑渐变卡片语言不变）；
  2. 功能范围：**一次性对齐参考 4.0.1 全集**（仓库网格、预设、服装、工艺、进度转移、模组清理、快速模式、多服务器路径、问题诊断全集、i18n 预留），分期实施但范围不砍；
  3. 激活系统：**去除，完全免费**（不捡回 ActivationService/VIP）；
  4. 开工方式：**严格按白板 Day-0 流程**（先文档门禁基线 → 稿图审批 → 生产代码）。
- **AI 自行确定的技术前提（已向用户报备，未获反对）**：
  - 不用参考项目的 ModHelper 服务端 dll；主进程直接读 SPT 服务器 `Aki_Data/Server/database` JSON（旧 Phoenix ServerDatabaseService 已验证可行）。
  - 中文第一语言，架构预留 i18n（key 集合一致门禁），一期不内置本地化编辑器。
- **参考项目功能全集清单**（补齐项）：仓库可视化编辑（网格/搜索/添加删除/旋转/容器编辑）、武器装备预设（Builds 导入导出）、服装解锁、工艺配方解锁、普通/Boss 大口袋切换、模组资料清理、存档间进度转移（分组勾选）、快速模式、多服务器路径管理、问题诊断规则全集（重复物品 ID/等级越界/任务矛盾/忠诚声望冲突等）、多语言。
