18 · 公告面板（稿图待批）
· 右上角小气泡（toast）只承载操作反馈（保存成功 / 备份完成等）；正式公告一律进本面板。
· 入口：标题栏右端、窗口三键左侧的铃铛按钮；有未读公告时铃铛带蓝点。
· 启动时拉到公告：自动弹出一次本面板（不逐条弹 toast）；未读点在关闭面板（或点「知道了」）后清除。
· 面板为居中模态卡片：顶部「公告」+ 数据来源徽章（远端 = 绿点「已同步最新」/ 缓存回退 = 琥珀「缓存内容」）；中部公告列表（标题 / 相对时间 / 正文 / 可选「查看详情」链接钮，未读项标题前带蓝点）；底部左提示文案 + 右「知道了」主按钮（清未读并关闭）。
· 关闭方式：右上角关闭钮 / 「知道了」/ Esc / 点遮罩。
