03 · 角色信息 —— iOS 26 暗色重设计说明
1. 本稿为旧 03 稿的视觉整体替换：功能点与信息架构逐项保留（昵称 / 阵营 / 角色 ID / 游戏版本 / 等级 / 经验 / 语音 / 头型 / 口袋 / 九格健康），仅换用 iOS 26 / macOS Tahoe Liquid Glass 视觉语言。
2. PMC / Scav 页签改为 iOS 26 分段控件（32pt，容器 fill-tertiary + 白 .27 指示器）；切到 Scav 时隐藏阵营 / 角色 ID / 游戏版本三行 PMC 专属项，与参考编辑器行为一致。
3. 角色 ID 与游戏版本为只读项，带「只读」小标签，不可编辑（对应存档中不应手改的字段）。
4. 等级用 iOS 26 步进器（94×29），经验为输入框 + 滑条示意；两者按服务器经验表双向联动，生产端实算。
5. 语音 / 头型 / 口袋为自绘下拉示意，选项来自服务器数据目录（Voices / Heads / Pockets），不在稿图里写死全集。
6. 健康状态九格为当前 / 最大双输入 + 比例血条；数值均为示意，生产端实读存档 Health 模块。
7. 导航为底部居中悬浮胶囊 dock（玻璃拟态，内容区底部留出 92px），选中项为白色玻璃胶囊按钮；顶部为 Windows 11 风格标题栏（右侧最小化 / 最大化 / 关闭，关闭悬停变红），与内容留出间距。dock 与窗口 chrome 在 01 / 02 / 03 / 04 一致（01 服务器选择为全窗独立屏，不并入 dock）；缩放脚本仅预览用。
