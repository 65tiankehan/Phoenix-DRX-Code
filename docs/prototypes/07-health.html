07 · 健康
1. 数据分组：参考编辑器无独立健康页——健康编辑位于「信息」页尾部的 9 个指标控件（7 个身体部位 + 水分 / 能量），Phoenix 将其单列成屏，分两组卡：身体部位（7 张：头部 / 胸腔 / 胃部 / 左臂 / 右臂 / 左腿 / 右腿）与水分 / 能量（2 张）。存档路径 characters.pmc.Health.BodyParts.{部位}.Health.{Current / Maximum} 与 characters.pmc.Health.{Hydration / Energy}；Scav 结构同构、同样可编辑（参考编辑器 Scav 不折叠健康区），顶层分段切换两套数据。
2. 编辑口径：参考编辑器每个指标为「当前 / 上限」两个可直接键入的数字框；稿图以 ±1 步进器示意（生产端为数字输入框）。保留参考联动规则：当前值 > 上限时上限自动抬高到当前值（参考 CharacterMetric.Current setter 行为）；上限可单独下调、不反向联动当前值，当前值最低 0。
3. 比例条为提案增补：卡内细条按 当前 ÷ 上限 比例填充，纯展示、不参与保存；参考编辑器无此视觉。稿图暂用主题蓝填充；低血量红色 / 低水分橙色等待状态色 token 入册后再启用，届时由视觉基线补声明。
4. 「全部回满」为提案增补：一键把当前页签全部指标当前值置为各自上限（水分 / 能量回 100）；参考编辑器无任何健康批量操作，此处为体验提案，请拍板取舍。
5. 数值示意：PMC 演示带伤状态（胸腔 62/85、右腿 28/65、左臂 45/60、水分 87/100 等），Scav 演示全新全满；参考项目与测试存档均无健康数值样本，生产端以真实 profile 为准，显示不做上限卡控。
6. 名称解析：中文名取本地化表（Head / Chest / … / HYDRATION / ENERGY 对应词条），英文小字为存档字段 key，便于对照原始数据。
7. 伤势效果：参考编辑器不支持骨折 / 出血等 Effects 的编辑，本稿未画；如需支持请另行拍板，将涉及存档 Effects 数组结构与阈值规则。
8. 导航：健康属角色域，dock 高亮「角色」；窗口 chrome 为 Windows 11 标题栏 + 底部居中胶囊 dock，与 02–06 一致；缩放脚本仅预览用，卡片列表区隐藏滚动条保留滚动。
