12 · 预设
1. 单页两子页签：参考编辑器中「预设」是顶级页签（Presets），内含三个右侧子页——武器（用户）/ 装备（用户）/ 武器（全局）。全局武器预设归第 10 屏图鉴浏览，本屏只做用户侧两个子页；数据源为档案的武器预设与装备预设两个列表（userbuilds.weaponBuilds / equipmentBuilds）。
2. 导航归属待拍板：参考中预设是独立顶级页签，故本稿提案在 dock 增设第 7 项「预设」（星形图标）并高亮；备选方案 = 并入「仓库」域子页签。请拍板后定稿。
3. 武器预设卡：卡头 = 预设名粗体 + 模组红三角（预设内任一零件不在物品库即整卡显示，提示该预设含模组添加的物品）+ 三动作【加入仓库 / 导出 / 移除】。卡体左半 = 图标 + 武器名 + 人机工效 / 后坐力向上 / 后坐力向后 三项数值（由预设零件自动算出，只读），右半 =「武器部件与配件」列表。加入仓库 = 把预设装配回仓库里的武器（对应参考 AddBuildToStash）。
4. 装备预设折叠卡：卡头 = 预设名 +【导出 / 移除】（参考口径没有「加入仓库」，装备一键穿回归角色页方案，如需可后续增补）；展开 = 完整 13 槽位行，样式与 09 / 11 屏装备槽同构（槽名 / 图标 + 物品名 / mod 红三角 / ID / 行内操作），口袋槽内嵌四格物品行，武器与容器槽带检视按钮（进第 10 屏检视视图）。装备子页顶部有兼容性警告条：从 3.8.0 以下版本 SPT 存档导出的装备预设不兼容（对应参考兼容性警告）。
5. 删除确认与备份：移除单条 / 移除全部均弹自绘确认弹层（文案对应参考「删除预设：确定要删除这个预设吗？/ 确定要删除所有预设吗？」，禁用原生弹窗）；所有写入动作执行前自动备份档案。导入 / 导出走系统文件选择（白名单例外）；导入自动校验文件内容（武器文件须含武器、装备文件须为自定型预设），重名自动加序号。
6. 过滤与空态：单框常显实时过滤当前子页（参考口径为各列表内嵌搜索框，Phoenix 收进工具栏）；两个空态均真实可达——过滤无结果显示「没有匹配的预设」，删空后显示「存档中没有任何武器/装备预设」。
7. 与第 10 屏闭环：第 10 屏检视弹窗底部「加入预设」即把当前装配写入本页武器预设列表，图鉴/检视的「加入仓库」反向把预设装回仓库，两屏共用同一份预设数据。
8. 示意说明：本稿为静态示意，预设与零件均为样例数据；正式版以真实档案为准，mod 三角、空槽、数值均按实际数据渲染。
