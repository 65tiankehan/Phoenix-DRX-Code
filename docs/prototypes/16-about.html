16 · 关于 — 设计说明
1. 形态与入口：参考编辑器的「关于」是主窗口最后一个顶级页签（AboutTab）。已拍板作 dock 第 10 项「关于」整页，与前 15 屏页签导航统一；参考七块内容重组为本屏五卡 + 一张全宽免责卡。
2. 文案对应：参考 tab_about_text（「此程序为编辑 SPT 服务器的存档程序」）→ 应用卡定位语；tab_about_developer（「开发者：」+ 作者 GitHub 链接）→ 应用卡开发者行；tab_about_latest_version（「最新版本：」+ 仓库链接）→ 版本卡；tab_about_spt_project_url（「SPT Project 网站」）→ 致谢卡官网链接。
3. 捐赠区块砍掉（拍板）：参考「支持开发者」含 Yoomoney 捐赠链接、Steam 交易链接、LTC 钱包地址与二维码；本项目免费开源、无收款渠道，关于页保持纯信息。
4. Discord 替代：参考提供 Discord 群组链接（加群讨论 / 提问 / 赞助）；本项目无社区群组，用 GitHub Issues 作为问题反馈入口承接讨论与提问职能。
5. 参考没有、我方新增：开源许可卡（MIT，铁律「免费开源」配套）、免责声明卡（非官方 / 与 Battlestate Games 及 SPT 团队无关 / 改档先备份——与 13 屏问题处理、14 屏备份联动）、致谢卡（SPT 项目 + SkiTles55 参考编辑器）。
6. 链接占位待确认：本应用的仓库 / 发布页 / Issues / 开发者主页地址均未定，稿图以占位链接示意（点击给轻反馈「链接地址确定后开放」，诚实原则显式标注，不放假链接）；致谢卡两条为真实外部链接（sp-tarkov.com、SkiTles55 仓库）。
7. 版本号：v0.1.0 为示意值，生产阶段从应用信息（构建配置）读取，不硬编码；「检查最新版本」是手动打开发布页，启动时的自动检查由 15 屏「检查更新」开关控制，两者互补不重复。
8. 布局：沿用 15 屏双列防留白布局——左列「应用 + 版本」、右列「开源许可 + 问题反馈 + 致谢」，顶部对齐各自成组；免责声明全宽置底作警示收尾（warn 色系，非危险红）。
9. 原生件禁用：文字链接为自绘样式（accent 色自绘 .lnk，禁用浏览器默认蓝紫链接色）；占位反馈用自绘 toast；本页无表单控件。
