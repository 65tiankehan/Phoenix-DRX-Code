1. 单页两子页签：参考编辑器中 Scav 装备是「仓库」页右侧第 4 子页（ScavTab），与 PMC 装备复用同一套控件（EquipmentSlotsList 五列槽位行），仅数据源不同（characters.scav.Inventory）——故本屏与 09 装备子页同构，顶部三段分段改为两段。Scav 与 PMC 共享口袋变体数据（characters.global.Pockets），界面无差异。
2. 清空装备：参考实现按钮位于装备列表底部（Equipment.xaml，Command=RemoveAllEquipment，仅在装有装备时可用），Phoenix 沿 09 口径收进页头动作区；点击弹确认框（文案对应参考 remove_equipment_items_caption「确定要删除全部装备吗？」），执行为后台任务，写入前自动备份。
3. 槽位行五列：槽名 / 图标+物品名（空槽灰字「空槽」）/ modded 红三角 / 物品 ID / 行内操作。红三角 = 不在物品库的模组物品（IsInItemsDB = false，参考实现用反转转换器在此类物品上显示）；行内操作 = 检视（仅武器类，对应参考 IsWeapon）→ 进入第 10 屏检视视图 + 删除（弹确认框，对应 remove_stash_item_caption）。
4. 口袋为特殊槽：参考实现口袋是装备里的特殊槽（SlotId = Pockets，模板 EquipmentSlotPockets），内嵌两列物品行：图标+名 / ID / 操作，空位显示「无物品」（tab_stash_no_items）；口袋容器本身模板 557596e64bdc2dc2118b4571。本屏装备子页保留该内嵌形态。
5. 「Scav 口袋」为增强子页：参考实现没有独立的口袋浏览页，Phoenix 增设第二子页把口袋内物品平铺成表 + 单框实时过滤，便于快速清理；口袋变体切换归属「角色」页（参考实现变体下拉仅出现在 PMC 角色页 Info 区，与头型下拉同款），Scav 侧只读展示当前变体。
6. 操作与 PMC 一致：Scav 装备页四类命令（移除物品 / 移除全部装备 / 检视 / 清空）与 PMC 装备页共用同一实现（参考 ScavTab 与 PMC StashTab 命令同源），所有删除动作均弹确认框、写入前自动备份。
7. 示意说明：本稿为静态示意，槽位与物品均为样例数据；正式版以真实档案为准，空槽与「无物品」态、模组物品三角均按实际数据渲染。
