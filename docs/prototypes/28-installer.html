设计注记

  • 窗口 460×360 恒定，四态同骨架同徽章语言（沿用 27 号稿图哲学：徽章承载状态——P 品牌 / 旋转环 / 绿勾 / 警示垃圾桶）。
  • per-user 安装：默认路径 %LOCALAPPDATA%\Programs\Phoenix-DRX，无需管理员权限；路径可改（浏览按钮），只改目录名以上部分。
  • 快捷方式两项开关：桌面默认关（玩家习惯各异）、开始菜单默认开且带说明（安装登记是「添加/删除程序」的卸载入口，不建议关——若真关掉，卸载只能走安装目录 Uninstall.exe）。
  • 安装中无操作按钮：总进度条 + 四步固定清单（解压 / 登记 / 快捷方式 / WebView2）；中止安装走标题栏关闭（弹确认，注记待拍板项 ②）。
  • 卸载即一屏：确认框 + 个人数据开关（默认关，保数据）；执行阶段复用安装中的进度样式但无步骤清单，完成直接关窗。
  • 静默模式不在此稿：/S 参数全流程无 UI（服务应用内更新链），直接落盘默认目录。
  • 待拍板：① 欢迎态要不要加「开源许可」一行小字链接（MIT 声明）；② 安装中点关闭 = 弹确认「确定中止安装？」还是不允许中止（装到一半中止会留半成品目录，建议：未完成解压前直接退、之后弹确认）；③ 完成态小贴士卡去留。
  • 引导条幅轮播（安装中态新增）：4 页轮换（4s/页，可手动点）——3 页版本特色（自动备份 / 仓库整理 / 人物养成，文案随版本配置）+ 1 页预留广告位；由 installer-config 驱动，新项目换文案即换轮播。
  • 广告位口径：带「推广」角标（与首页动态栏推广同款语言），数据来自 Opendata 公告仓 sponsor 条目（同一数据源，两处复用）；无赞助商时该页自动回落为「赞助招租」自宣页；点击可开外链（系统浏览器）。
  • 条幅为四态常驻件：欢迎 / 安装中 / 完成 / 卸载都保留轮播，内容稀疏的态用 margin-top:auto 吸附动作区上方——空闲区即广告位，不再有大空白；卸载态是否展示广告由 installer-config 单独开关（默认开，可关）。广告卡加大（44px 图标 + 两行文案），窗口 460×460 四态恒定；完成/卸载态各补一行真实信息（安装位置 / 占用空间）避免空档。
