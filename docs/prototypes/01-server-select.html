设计说明（审批后删除）
1. 本页为第 1 屏「服务器选择」重设计稿：按 E:\ios26-design-system-main（iOS 26 / macOS Tahoe）暗色体系整体重做，功能点与旧稿逐项对应，仅视觉替换。
2. 视觉基线转向：窗口 r12 + 纯黑底、标题栏 36px 高斯模糊材质、强调色 iOS 蓝 #0091ff；token 仍用 --phx-* 单一来源，值集以本稿为准（获批后同步重写视觉基线.md 与 tokens.css）。
3. 「可用」= 目录校验通过：能找到 SPT.Server.exe、SPT\user\profiles 等关键文件（沿用参考项目 4.0.1 的校验标准）；「不可用」直接显示缺失原因，「进入编辑」置灰。
4. 「3 个存档」= 读取该服务器 SPT\user\profiles 下的存档文件数量（生产端实读）。
5. 「添加服务器目录」走系统目录选择框（系统级例外白名单）；添加后立即校验并写入列表，支持多服务器管理。
6. 移除确认为自绘 Alert（270pt 宽、r14 材质卡），非系统对话框；生产端点「移除」弹出，本稿静态展示于窗口下方。
7. 本页保持全窗独立屏（无 dock）；02/03/04 屏以底部居中胶囊 dock 导航，窗口 chrome（Windows 11 标题栏：右侧最小化 / 最大化 / 关闭）四屏一致。
8. 稿图内置缩放脚本：把 1180×820 模拟窗体等比缩进当前视口，仅预览用；生产为固定尺寸无边框窗，列表超出一屏时滚动。
