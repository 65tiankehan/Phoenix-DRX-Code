08 · 藏身处
1. 单页三子页签：参考编辑器「藏身处」为顶级页签内的右侧页签组（区域 / 解锁生产配方 / 进行中生产），且数据只读 PMC——Scav 无藏身处，本屏不做阵营分段（页头标注「仅 PMC」）。Phoenix 将右侧页签改为顶部三段分段。存档路径 characters.pmc.Hideout：Areas（区域等级数组）与 Production（进行中生产字典）；配方解锁清单存于 PMC.HideoutProductions。
2. 区域编辑口径：对齐参考「数字步进 + 滑条双控件同绑一个等级值」——稿图用 ±1 步进器与自绘滑条（生产端为数字框 + 滑条）。等级上限 MaxLevel = 服务器 database hideout/areas.json 该区域 stages 数 − 1（稿图数值为示意）；改某区域等级时父子区域联动（参考 HideoutArea.Level setter 行为：等级卡控后再同步父 / 子区域）。
3. 等级比例条为提案增补（延续 07 已批准的方案语言）：按 当前等级 ÷ 上限 填充，纯展示；参考编辑器无此视觉。
4. 生产配方清单：行 = 最终产品图标 + 名称 + 所属区域 + 「已获得」勾选（对应参考 Added 布尔，勾选即把该配方写入存档解锁清单）；「添加全部配方」对应参考 AddAllCrafts。
5. 进行中生产（实验性）：顶部警示横幅对齐参考编辑器的 Warning 区。行内「设为已完成」仅在未完成时可用（参考 SetCraftFinished：把剩余小时折算回开始时间戳后置满）；状态两态「进行中 / 已完成」；进度百分比为提案增补（参考无进度列，但存档有进度与总时长字段）。
6. 批量与确认：「全部完成」仅当存在未完成生产时可用；「移除全部」与行内删除均弹确认框（参考编辑器行为），生产端走统一确认弹窗组件。
7. dock 第 5 项为提案，待拍板：藏身处不属于现有 4 项（首页 / 角色 / 任务 / 商人）任何一域，本稿新增第 5 项并高亮——此前「dock 超 5 项再裁决」的挂起事项提前触发，请拍板是否接受 5 项 dock。
8. 导航与示意：中文名取本地化表 hideout_area_{type}_name 词条，英文小字为区域 / 物品 key，便于对照原始数据；区域、配方、生产条目与数值均为示意，生产端实读真实 profile 与服务器 database；橙色警示 / 红色删除悬停为状态色示意，待 orange / danger token 入册后由视觉基线补声明；窗口 chrome 与 02–07 一致，缩放脚本仅预览用，卡片列表区隐藏滚动条保留滚动。
