17 · 更新薄窗设计说明
· 独立薄窗：非主窗内页面，独立 WebviewWindow（约 420px 宽，按内容自适应高）。标题栏文案「Phoenix 更新」，无窗口缩放按钮。
· 实心底：透明小窗禁用玻璃拟态，一律 --phx-win-bg 实心 + CSS 圆角 + --phx-shadow-win（章程铁律）。
· 三态流转：① 发现新版本（版本对比 + 更新内容 + 立即更新/稍后提醒）→ ② 下载中（进度 + 速度，可收起后台继续）→ ③ 下载完成（重启安装，带未保存提醒）。
· 启动静默检查：应用启动后静默查询更新源，无更新时零 UI（不弹窗、不 toast）；有更新才弹此薄窗。「稍后提醒」本次会话不再打扰，下次启动重新提示。
· 更新内容来源：发布 Release 的 changelog 文本，纯文本逐行渲染为要点（无富文本解析）。
· 失败兜底：检查/下载失败均静默（仅日志），不打扰用户；用户亦可不设手动入口（一期不做「检查更新」按钮，见下）。
· 未落地项（待拍板）：设置页是否加「检查更新」手动入口——一期建议不加，保持最小实现。
