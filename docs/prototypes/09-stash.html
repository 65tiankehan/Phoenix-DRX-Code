09 · 仓库网格
1. 单页三子页签：参考编辑器「仓库」为顶级页签（StashTab），内部右侧页签组含 4 子页——仓库 / 添加物品 / PMC 装备 / Scav 装备。本屏做前三子页，Scav 装备与口袋划归第 11 屏「Scav / 口袋」（页头已标注）；Phoenix 将右侧页签改为顶部三段分段。存档路径 characters.pmc.Inventory（stash / equipment / 口袋容器对象）。
2. 表格口径，非游戏方格：参考编辑器仓库主体是数据表格而非 Tarkov 方格——列 = 图标+物品名 / modded 标记 / 物品 ID / 操作。Phoenix 沿用表格口径；红三角 = 不在物品库的 modded 物品（IsInItemsDB = false）；名称与 ID 双过滤框对应参考表头内嵌搜索（StashItemName / Id，实时过滤）。
3. 行内操作三钮：检视（仅武器，IsWeapon）→ 进入第 10 屏检视视图；开容器（IsContainer）→ 容器内容为同款表格的二级窗口（参考 ContainerWindow 600×400，复用 ItemsGrid + ItemsAdding）；删除（参考条件：RemovingAllowed 且物品非空）。行内删除与页头「清空仓库」「清空装备」均弹确认框（对应 RemoveItem / RemoveAllItems / RemoveAllEquipment 均走 YesNo）。
4. 货币与附加行数：三货币 ₽ / € / $ 胶囊 + 圆形加号（参考 MoneyPanel，加钱参数 = 捆数 × 物品 Tpl）；参考在仓库含 modded 物品时显示警告并禁用加钱区（ContainsModdedItems → tab_stash_mod_items），生产端沿用。附加行数 = Pmc.StashRowsBonusCount，步进 ±2、最小 0，参与仓库尺寸计算（参考 NumericUpDownExt Interval=2）。
5. 添加物品页：左分类树（图标 + 名，层级，对应 ItemsAdding TreeView）+ 右可添加列表（AddItem 命令，行尾「添加」钮）；搜索框带「含描述」勾选（FilterName + FilterDescriptions）；顶部警示横幅原文取自参考本地化 tab_stash_fully_equipped_weapons_and_gear；「全部物品」对应 ShowAllItems——参考在添加被阻断（AddItemsBlocked）时把该钮显示于底部，Phoenix 统一收进页头动作区，恒显。
6. 装备子页：槽位行 = 槽名 / 图标+名（空槽灰字）/ modded 三角 / ID / 操作，对齐参考 EquipmentSlotsList 五列模板；口袋（Pockets）为特殊槽，内嵌物品列表（参考 EquipmentSlotPockets 模板），空槽显示「无物品」；装备页无过滤框（参考口径）。
7. dock 第 6 项为提案，待拍板：仓库属高频功能，本稿在 08 已批准的 5 项 dock 之上新增第 6 项「仓库」并高亮；备选方案为不加 dock、由首页卡片进入仓库。请拍板取舍。
8. 旋转不实现 + 示意说明：交接卷功能清单提到的「旋转」经全仓核查参考编辑器无对应实现（StashTab / GridFilters 无 Rotate 相关代码），判定为清单誊写误差，不做；物品图标用首字占位，生产端用真实图标资源；物品名 / ID / 数值均为示意，生产端实读 profile 与服务器数据库；橙色警示 / 红色删除为状态色示意，待 orange / danger token 入册后由视觉基线补声明；窗口 chrome 与 02–08 一致，缩放脚本仅预览用，卡片列表区隐藏滚动条保留滚动。
