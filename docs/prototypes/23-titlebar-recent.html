规格注记
1. 最近访问：真实记录（本地保存最近 6 个导航页，顶栏只展示 3 个；不含服务器选择/托盘/更新薄窗这类非导航屏）。切换页面即刷新，当前页在组内显示选中态（accent 图标 + 提亮底）。
2. 与 dock 的关系：两者共用同一路由高亮口径（含角色域 / 仓库域子页归并），不会出现顶栏亮一个、底栏亮另一个的矛盾。
3. 顶栏 tab 组：高 24px、圆角 7px、图标 13px、文字 11px；组底 --phx-fill-tertiary + 0.5px --phx-sep 描边，选中 --phx-fill-secondary。
4. dock 缩一号：只动几何（图标 22→19、项宽 56→50、项高 46→42、logo 34→30、内边距 6→5），字号仍 10px（下限，再小中文读不清）；液体滑块与 hover 光斑规格不变。
5. 拖拽：tab 组是交互元素，需 no-drag；顶栏其余区域仍整条可拖。
6. 动效：tab 只在 hover/选中态动 background/color（--phx-dur-fast）；无新增位移动画，reduced-motion 无差异。
7. 音效：点 tab 走 playSound('nav')，与 dock 同档。
