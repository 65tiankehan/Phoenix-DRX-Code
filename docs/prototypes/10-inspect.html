10 · 检视 / 图鉴
1. 单页两子页签：检视 = 武器改装视图弹窗（参考 WeaponBuildWindow，主体为 WeaponBuildView，标题 = 物品本地化名，红三角 = 预设含模组添加的零件）；图鉴 = 服务器数据库自带的全局武器预设库（参考 BuildsTab 第三子页「武器（全局）」，只读、不可移除）。
2. 检视入口与移除权：参考入口 OpenWeaponBuildWindow(item, inventory, removeAllowed)——从仓库进入 = true（弹窗显示「移除」）；从预设页进入 = false（不显示）。本稿背板为仓库表格示意，实际弹窗盖于仓库页之上（遮 dock 不遮标题栏）。
3. 弹窗三动作：加入预设 = 存入用户武器预设（参考 ImportBuild）；导出 = 存为预设文件（系统级文件选择属白名单例外）；移除 = 从仓库删除该预设物品，生产端先弹确认框（参考 YesNo 弹窗），本稿简化为直接删行。按钮置于底部脚区为 Phoenix 暗色沉浸改编（参考为窗口顶行）。
4. 零件列表口径：只列改装零件并跳过弹匣内弹药（参考实现跳过 patron_in_weapon / cartridges 槽位）；指标 = 人体工学 / 垂直后坐力 / 水平后坐力（对齐参考 WeaponBuildView 三行）。
5. 红三角说明：模组零件警告在参考端为原生提示（"预设包含由模组添加的物品"），生产端改自绘提示（视觉基线禁原生 title）。图鉴卡 2 示意含模组零件的全局预设。
6. 10 / 12 屏边界提案，待拍板：第 10 屏 = 检视弹窗 + 图鉴（全局武器预设浏览）；第 12 屏「预设」= 用户武器预设与用户装备预设管理（列表 / 导入 / 导出 / 删除）。图鉴的生产端入口（仓库域子页签 or 预设页）待拍板，本稿暂放仓库域。
7. 数据为示意：图鉴内容生产端实读服务器 database 全局预设（名称 / 零件 / 指标）；卡片「加入仓库」= 把预设物品复制进存档仓库（参考 Add to stash）。
