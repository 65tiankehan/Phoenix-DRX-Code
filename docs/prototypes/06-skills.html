06 · 技能 / 武器熟练
1. 数据分组：对应参考编辑器「技能（Skills）」与「武器熟练（Mastering）」两页，本稿合一屏两组卡，行式列表：技能名与英文名 · 经验值步进（±100，对齐参考编辑器 Interval=100）· 滑杆（步长 100），两控件双向联动。PMC / Scav 顶层分段切换两套独立数据（存档路径 characters.pmc.Skills.Common / .Mastering，Scav 同构）。
2. 上限：普通技能统一上限 5100（51 级 × 100 点，参考编辑器默认值）；武器熟练上限为各武器精通 Level2 + Level3 之和（每人不同，稿图以 4000 示意，组头注「上限随武器」）。
3. 行内等级（Lv n）为提案增补：经验值 ÷ 100 取整，纯展示换算，保存时不做任何等级重算联动——参考编辑器无逐行等级显示，此处为可读性提案，请拍板取舍。
4. 一键设置全部：点工具行按钮弹自绘浮层（步进 + 滑杆 + 应用），把统一值应用到当前页签的全部技能与武器熟练（对齐参考编辑器底部统一设置面板）；「全部拉满」把当前页签所有行置为各自上限，跳过以 bot 开头的技能（BotReload / BotSound，机器人内部技能，拉满无意义）——与参考编辑器口径一致。设为 0 即重置，无专用重置按钮。
5. 名称解析：优先取本地化表中文名；无映射时原样显示 Id（BotReload / BotSound 即演示此回退）；武器熟练在本地化缺失时回退拼接该武器模板列表（生产端行为，稿图未演示）。
6. 空态：Scav 页签武器熟练为空演示空态卡；生产端任何页签任一分组为空数组均显示同款空态。
7. 搜索：按名称 / 英文名实时过滤，与 PMC / Scav 分段叠加生效；分组卡头可折叠。
8. 导航：技能属角色域，dock 高亮「角色」；窗口 chrome 为 Windows 11 标题栏 + 底部居中胶囊 dock，与 02 / 03 / 04 / 05 一致；缩放脚本仅预览用。计数徽标为真实数据量（普通技能 54 项 / 武器熟练 13 类），行内容为示意抽样。
