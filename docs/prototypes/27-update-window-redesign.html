设计注记（相对现版的改动）

  • 窗口恒定尺寸：三态同骨架、同尺寸 420×396，生命周期内不再变高矮——高度自适应从「常态机制」降级为「超长 notes 的滚动兜底」，彻底消灭底部空白/挤出一类问题。
  • 状态徽章承载语义：available 蓝色下行箭头 / downloading 进度环（环走进度、中心小百分比）/ downloaded 绿勾，同形同位（44px 圆角方），情绪由颜色表达。
  • 版本对进副题、三态常驻：`0.1.7 → 0.1.8` mono 排版，新版本号用主色；不再单独占一行 chips（available 独有的版本行取消）。
  • 下载中：进度是主角：进度环进徽章 + 进度主卡（28px 大百分比 / 进度条 / MB 量词）；轮播由 118px 插画卡降为 56px 条幅（小图标 + 单行文案 + 细点），安利不抢戏；右上角无意义的速度值改为「剩余约 N 秒」（速度未知时该位留空）。
  • 「后台下载」语义前置：下载中副题直接写明「关闭窗口将转后台下载」，按钮与关窗行为同义，不再是两个概念。
  • 待拍板：状态三新增「本次更新内容」回顾卡（复用 notes 真实数据、填满内容槽）——若嫌重启前多余可去掉，去掉后该态高度可比另两态矮（回到内容自适应）。
