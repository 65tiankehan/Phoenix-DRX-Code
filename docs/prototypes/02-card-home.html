设计说明（iOS 26 / macOS Tahoe 暗色重设计）
  1. 本稿为视觉语言整体替换：功能点与信息架构与旧版 02 完全一致，17 个入口逐项保留，无增无减。
  2. 导航结构改为底部居中悬浮胶囊 dock（玻璃拟态 blur + 描边 + 投影）：品牌圆标 + 首页 / 角色 / 商人；服务器选择（01）仍为全窗独立屏，不并入 dock。
  3. dock 悬浮于窗口底部中央（内容区底部留出 92px），选中项为白色玻璃胶囊按钮，图标转强调色；顶部为 Windows 11 风格标题栏（40px，与「首页」等内容留出间距），右侧平铺最小化 / 最大化 / 关闭（关闭悬停变红）。
  4. 档案概览卡：头像 + 档案 ID 可下拉切换 + 等级 / 派系；三种货币横排等宽数字展示，数值均为示意，生产端实读存档。
  5. 仪表台按 2×2 面板分组：角色数据 6 项 / 维护与工具 3 项 / 物品与经济 5 项 / 进度与任务 3 项，与旧稿逐一对应。
  6. 「问题检测」红色计数徽章为示意（3 项待处理），生产端由问题检测逻辑实算。
  7. 「返回服务器选择 / 保存修改」为主操作位；保存修改前自动备份。
  8. 窗口 chrome（Windows 11 标题栏、dock 底部居中悬浮）与 01 / 03 / 04 保持一致；缩放脚本仅预览用，生产端由 Electron 窗口接管。
