04 · 商人 —— iOS 26 暗色重设计说明
1. 本稿为旧 04 稿的视觉整体替换：8 商人卡 + 跳蚤市场卡逐项保留（中英文名、忠诚等级、声望、累计销售、解锁开关），仅换用 iOS 26 / macOS Tahoe Liquid Glass 视觉语言。
2. 解锁开关为 iOS 26 toggle（51×31，ON 用强调色蓝）；关闭时该卡忠诚等级 / 声望 / 累计销售一并禁用（示意态）。
3. 忠诚等级用 iOS 26 步进器（94×29），范围 1 – 4 为示意；上限 = 服务器 base.json 忠诚段数量，生产端实算。
4. 「全部拉满」：等级推到各自上限并解锁全部；生产端还需联动声望 / 累计销售达标（见参考编辑器实现）。
5. 不设 PMC / Scav 页签：参考编辑器对 Scav 商人无编辑入口（诚实原则，不画没有的能力）；黑商 Fence 的改动生产端会自动同步 Scav 名下同 ID 商人。
6. 跳蚤市场卡无解锁开关，仅评分数值（范围 −20 起 · 精度 0.01），对应存档跳蚤评分。
7. 导航为底部居中悬浮胶囊 dock（玻璃拟态，内容区底部留出 92px），选中项为白色玻璃胶囊按钮；顶部为 Windows 11 风格标题栏（右侧最小化 / 最大化 / 关闭，关闭悬停变红），与内容留出间距。dock 与窗口 chrome 在 01 / 02 / 03 / 04 一致（01 服务器选择为全窗独立屏，不并入 dock）；缩放脚本仅预览用。
